# Session: teamai-cli Teaching Session (teach skill)

## What happened
Used the "teach" skill to systematically learn teamai-cli from a team admin's perspective. Created a structured teaching workspace with 5 lessons covering the full admin workflow.

## Key learnings

### teamai-cli as a team collaboration layer
- Skills, rules, hooks, MCP, env all live in a shared Git repo
- push → MR → pull flow distributes config to all team members
- SessionStart hook auto-pulls latest team config on every AI session

### Repository structure
- `skills/` = on-demand, scenario-triggered (with YAML frontmatter: name, description, tags)
- `rules/` = always-on constraints injected into every session
- `agents/` = custom AI roles (YAML)
- `hooks/hooks.yaml` = lifecycle hooks (SessionStart, Stop, PreToolUse)
- `culture.md` = always-injected team values
- `env/` = shared variables (NO secrets!)
- `teamai.yaml` = repo metadata, npm packages, recall default

### Distribution pipeline
1. Role namespace expansion (primaryRole + additionalRoles → namespace set)
2. Tag subscription overlay (cross-namespace skill subscription)
3. Exclude list filter (personal exclusions, `teamai skill exclude`)
4. Final sync to local AI tools

### Role system
- Admin defines roles with `teamai roles add <id> --namespaces a,b,c`
- Members choose with `teamai roles set <id>`
- Safe degradation if admin deletes a role: falls back to full sync with warning
- `--role` flag when pushing: targets a specific namespace

### Knowledge management
- Recall is OFF by default — must explicitly enable via teamai.yaml or `teamai recall enable`
- Learnings auto-captured via friction scoring (interrupt, toolReject, correction, retries)
- Import from repos/orgs/MRs with `teamai import`
- Codebase knowledge graph via tree-sitter AST + heuristic extraction
- Maintenance: prune → archive → update-quality cycle

### Admin daily rhythm
| Frequency | Action |
|-----------|--------|
| Weekly | `teamai digest` |
| Weekly | `teamai recall maintenance --prune --dry-run` |
| As needed | `teamai recall promote <id>` |
| As needed | Push new skills/rules |
| Quarterly | `teamai recall maintenance --update-quality` |
